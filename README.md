# 青年志海报生成器：GitHub 网页上传版

这是已经编译完成的网站文件，不需要安装软件或执行命令。

## 上传方法

1. 不要把 ZIP 文件直接提交到 GitHub。
2. 解压 ZIP，进入 `qingnian-poster-github-web-upload` 文件夹。
3. 在 GitHub 仓库首页点击 **Add file → Upload files**。
4. 把本文件夹内部的全部文件和 `assets` 文件夹拖入上传区域，然后提交。
5. 进入 **Settings → Pages**。
6. Source 选择 **Deploy from a branch**。
7. Branch 选择 **main**，Folder 选择 **/(root)**，点击 **Save**。

## 说明

- 网站运行所需的字体、Logo、默认人物和程序文件都已包含。
- 每个文件都小于 GitHub 网页上传的单文件限制。
- 完整可编辑源码保存在另一份 `qingnian-poster-github-small` 文件包中，不需要上传到这个发布仓库。
